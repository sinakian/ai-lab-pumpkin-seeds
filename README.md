# Pumpkin Seeds Classification Project

Welcome to our project! 
Everything has been configured to run automatically. The dataset is hosted on GitHub and will be imported directly into the notebook when run.

### How to Run This Code:

**1. Install Dependencies**
Please open your terminal in this project directory and run the following command to install the required libraries:
`pip install -r requirements.txt`

**2. Run the Model**
Open the `Pumpkin_Dataset.ipynb` file in your preferred Jupyter environment (VS Code, JupyterLab, etc.) and simply click **"Run All"**.
